One video. Multiple platforms. Zero monthly subscriptions.

SocialRelay is an open-source, self-hosted social media automation engine. Paste an authorized Instagram Reel link, automatically transcode to 9:16 vertical 1080×1920 via FFmpeg, prepare compliant metadata, and publish to YouTube Shorts and Instagram Reels with one click from your private execution host.

Install Locally Read Documentation

One-Click Quick Publish

Paste an authorized URL, auto-prepare metadata and 9:16 video in the background, and publish with real-time step-by-step verification.

Private Execution Surface

Your SQLite database, Fernet-encrypted OAuth tokens, and video storage stay 100% on your own hardware (localhost or private VPN).

Deterministic + Local AI

Automatic caption-to-title conversion works offline out of the box, with optional local Ollama enhancement and zero paid AI APIs.

Idempotent & Resilient

Persistent SQLite job queue, 20-state lifecycle machine, and SHA-256 idempotency keys prevent duplicate uploads across restarts.

Quick Installation

GitHub Pages hosts this public documentation portal only. The FastAPI backend, FFmpeg engine, and automation worker run privately on your machine:

git clone https://github.com/J5pecter/insta-to-yt.git
cd insta-to-yt

# Windows PowerShell
.\infrastructure\scripts\setup-windows.ps1
.\infrastructure\scripts\start-windows.ps1

# Linux / Docker
docker compose up -d --build
